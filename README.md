Orders Analytics – Power BI Dashboard

An interactive dashboard created in Microsoft Power BI to analyze order data and present key business insights.

Dashboard Preview:

- Key Features
- Total number of orders
- Key performance indicators (KPIs)
- Order analysis over time
- Order status analysis
- Product category analysis
- Interactive filters and slicers
- Date-based analysis
  
Tools & Technologies:

- Microsoft Power BI
- DAX
- Power Query
